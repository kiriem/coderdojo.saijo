About

「これ、つくったんだ」を
話す日。

Special Presentation Day は、中・四国地方のいろいろな場所から集まって、 いま取り組んでいることをおたがいに話す会です。 じょうずなプレゼンをする必要はありません。 「なんでつくったの？」「ここが大変だった」—— そのまま話してくれるのが、いちばんおもしろい発表になります。

all_inclusive

途中でもいい

完成していなくてもかまいません。作っている途中のものや、うまくいかなかった話も大歓迎です。

communities

なかまに出会える

学校でも家でも、ひとりでコツコツ作っている人は多いもの。同じように何かを作っている人に会えます。

lightbulb

次のヒントが見つかる

人に話すと、自分の考えが整理されます。もらった感想から、次に作りたいものが見えてきます。

FAQ

よくある質問

プログラミングができなくても参加できますか？ add

できます。パソコンやタブレットを使って作ったものであれば、絵でも、物語でも、動画でも、音楽でも、調べたことでもかまいません。プログラミングの経験はまったく必要ありません。

CoderDojo に参加したことがなくても大丈夫ですか？ add

大丈夫です。CoderDojo に通っていない方も、中・四国地方にお住まいの小学生〜高校生であればどなたでも参加できます。はじめての方がほとんどです。

人前で話すのが苦手です。 add

ほとんどの人がそうです。じょうずに話す必要はまったくありません。紙に書いてきたものを読んでも、画面を見せながらぽつぽつ話しても大丈夫です。緊張したときは、スタッフが横についてサポートします。

作品がまだ完成していません。それでも発表できますか？ add

できます。むしろ「いま作っている途中のもの」の発表は大歓迎です。どこで行き詰まっているかを話すと、聞いている人からヒントをもらえるかもしれません。

見学だけの参加もできますか？ add

できます。「どんな感じか見てみたい」という方も歓迎です。申込みのときに見学希望とお伝えください。当日に「やっぱり話してみたい」となってもかまいません。

発表に使うパソコンは持っていきますか？ add

使い慣れた機材で話せるよう、できるだけご自身のパソコンやタブレット、作品をお持ちください。準備が難しい場合は、申込みのときにご相談ください。

保護者も一緒に行けますか？ add

ぜひご覧ください。会場には保護者の方の見学スペースをご用意します。小学生の方は、できるだけ保護者の方とお越しください。

発表の時間はどのくらいですか？ add

申込みの人数によって決まります。詳しい発表時間や順番は、お申し込みいただいた方に後日ご案内します。
